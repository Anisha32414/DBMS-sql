# LeetCode SQL Solutions

This repository contains **LeetCode SQL problems and their solutions**, designed to help build a strong foundation in SQL and improve problem-solving skills.

### Topics Covered

* SELECT & WHERE
* Aggregate Functions
* GROUP BY & HAVING
* ORDER BY
* Joins
* Subqueries
* Aliases
* Window Functions
* CTEs
* Constraints
* Other important SQL concepts

Each problem includes a **SQL query solution** for practice and interview preparation.
